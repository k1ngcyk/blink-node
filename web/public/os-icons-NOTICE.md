# Operating system marks

Ubuntu, Debian, Red Hat, Apple and Windows marks are supplied by the project's existing Tabler Icons (MIT).
Alpine Linux, Arch Linux, Fedora, CentOS and Rocky Linux SVG paths are from Simple Icons (CC0-1.0):
https://github.com/simple-icons/simple-icons/tree/develop/icons

The marks identify the operating system reported by a server. Trademarks belong to their respective owners.
